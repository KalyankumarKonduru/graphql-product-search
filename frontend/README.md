# GraphQL Product Search - React Frontend

A React frontend with **Apollo Client** for GraphQL data fetching, featuring real-time search, pagination, and optimistic UI.

## Tech Stack

- **React 19** + **TypeScript**
- **Apollo Client** - GraphQL state management
- **Tailwind CSS** - Styling
- **Vite** - Build tool
- **MSW** - API mocking for tests
- **Web Vitals** - Performance monitoring

## Features

- 🔍 Debounced search with autocomplete
- 📄 Cursor-based pagination with infinite scroll
- ⚡ Optimistic UI for mutations
- 🧪 GraphQL mocking with MSW
- 📊 Web Vitals monitoring
- 🛡️ Error boundaries

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

```env
VITE_API_URL=http://localhost:4000/graphql
```
